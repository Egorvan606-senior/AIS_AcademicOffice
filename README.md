Учебный каркас репозитория: приказы, успеваемость (БРС), GPA и стипендии.
Это структура будущего решения; исполняемая АИС в этой работе не создаётся.

## Каталоги
- src/Dean.Core — доменная модель и правила расчёта GPA и стипендий.
- src/Dean.Infrastructure — интеграции с Moodle, 1С и хранилищем данных.
- src/Dean.UI — интерфейс деканата.
- tests/Dean.Tests — место для модульных тестов.
- docs/architecture — диаграммы и архитектурные решения.
- docs/openapi — контракты API.
Пустые каталоги сохраняются в Git с помощью файлов .gitkeep.

## Проверка
git status --untracked-files=all
git status --short --ignored
git check-ignore -v src/bin/Debug/test.dll
git lfs track
git check-attr filter diff merge text -- sample.zip sample.bak
git ls-files --eol

Контрольные файлы в bin, obj, .vs и private-data созданы специально для
проверки исключений и не входят в коммит. Реальных данных студентов нет.
Правила *.bak и *.zip передают допустимые крупные файлы в Git LFS;
LFS не шифрует данные и не заменяет проверку прав доступа.

## Права доступа
Репозиторий локальный, удалённый origin не подключён. Правила командной
работы описаны в docs/architecture/access-policy.md. Серверная защита веток
в этой работе не включалась: отдельного шага настройки сервера в задании нет.
